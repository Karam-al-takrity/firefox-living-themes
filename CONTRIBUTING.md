# Contributing

New themes, fixes for newer Firefox versions, and macOS or Linux testing are all welcome.

## Reporting a problem

Open an issue with your Firefox version, your operating system, which theme you were using, and a screenshot. For script problems, also include what the Browser Console shows (Ctrl+Shift+J).

Firefox's internal class names change between versions, so "this broke on version X" is useful even without a fix.

## Adding a theme

1. Create `chrome/themes/<name>/` with `userChrome.css` and `userContent.css`. Add `theme.json` for the menu title, description and icon:
   ```json
   { "title": "My Theme", "description": "One short line", "icon": "assets/icon.svg" }
   ```
2. Add an import for it to `chrome/userChrome.css` and `chrome/userContent.css`:
   ```css
   @import url("themes/<name>/userChrome.css") -moz-pref("<name>.active");
   ```
3. Add one more link to the chain in `chrome/themes/nocturne/gate-*.css`. Nocturne is the default and loads only while every other theme is off, and each file in the chain checks one theme.

The palette menu finds new theme folders by itself.

## Rules for themes

- **Namespace everything.** Custom properties are `--<name>-*` and keyframes are `<name>-*`, so themes can't collide.
- **Relative paths only.** Use `url("assets/...")` so the folder works wherever it's copied.
- **No network.** Nothing may load from the internet: no remote fonts, images or scripts. Draw your own art, or use art you have the rights to.
- **Support freeze.** `@media -moz-pref("<name>.freeze")` must stop all animation, and `prefers-reduced-motion` must be respected.
- **Leave security pages alone.** Never style `about:certerror`. People need to recognise real warnings.
- **Keep the browser usable.** Never cover the toolbars or a page someone is reading.

## `chrome.js` gets extra review

A theme's optional `chrome.js` runs with full browser privileges through the theme loader. Pull requests that add or change one must explain what it does. Code that touches the network, reads or writes files, or uses obfuscated or minified source won't be accepted. Please read `chrome.js` changes carefully when reviewing.

## Generated files

Some assets are generated by the scripts in `tools/` (`python tools/make_*.py`). Edit the script, not its output. Each script's first lines list what it writes.

The `tools/*-preview.html` pages let you check the art outside Firefox. Run `python -m http.server` in the repo root and open them from `http://localhost:8000/tools/`.
